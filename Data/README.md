
# IEEE-CIS Fraud Detection Dataset

This project it uses the IEEE-CIS Fraud Detection dataset.

Source:
https://www.kaggle.com/competitions/ieee-fraud-detection/data

The original dataset is not uploaded to GitHub.

To reproduce the experiments:

1. Access the the Kaggle competition page.
2. Download the transactions and identity data files.
3. Open the notebooks in the numerical order.
4. Update the dataset paths to match the environment.

The notebooks it apply preprocessing and chronological data splitting before model training and the evaluation.
